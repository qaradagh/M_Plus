# M_Plus

اندیکاتور و استراتژی تستر برای **TradingView (Pine Script v6)**.

منبع اصلی توضیحات: فایل صوتی/ویدیویی که باید به متن تبدیل و در `docs/` قرار بگیرد.

---

## ساختار پوشه‌ها

| مسیر | محتوا |
|---|---|
| `docs/transcript/` | متن پیاده‌شده‌ی فایل صوتی (`.txt` / `.md`) |
| `docs/screenshots/` | اسکرین‌شات‌های ویدیو (`.png` / `.jpg`) |
| `indicators/` | کد اندیکاتور (`.pine`) |
| `strategies/` | کد استراتژی قابل بک‌تست (`.pine`) |

> ⚠️ خود فایل‌های صوتی/ویدیویی در `.gitignore` هستند و نباید commit شوند —
> گیت‌هاب سقف ۱۰۰ مگابایت برای هر فایل دارد. فقط متن و تصویر را آپلود کنید.

---

## چک‌لیست اطلاعات لازم

برای اینکه کد بدون حدس‌وگمان نوشته شود، این موارد باید از دل صوت/ویدیو مشخص شوند.
اگر transcript جایی مبهم بود، همان بند را علامت بزنید تا در موردش سؤال بپرسم.

### اندیکاتور

- [ ] بر چه پایه‌ای محاسبه می‌شود؟ (میانگین متحرک، RSI/ATR، پرایس‌اکشن، ساختار بازار، حجم، …)
- [ ] فرمول یا منطق دقیق محاسبه
- [ ] پارامترهای ورودی و مقدار پیش‌فرض هرکدام
- [ ] نحوه‌ی نمایش روی چارت (خط، هیستوگرام، فلش، رنگ‌بندی کندل، پنل جدا)
- [ ] شرط دقیق صادر شدن سیگنال خرید و فروش
- [ ] آیا سیگنال روی کندل بسته‌شده صادر می‌شود یا لحظه‌ای؟ (تعیین‌کننده‌ی repaint)

### استراتژی

- [ ] شرط ورود **لانگ**
- [ ] شرط ورود **شورت** (اگر دوطرفه است)
- [ ] حد ضرر (SL) — ثابت؟ بر پایه‌ی ATR؟ زیر سوئینگ؟
- [ ] حد سود (TP) — عدد ثابت؟ نسبت R؟ چند پله‌ای؟
- [ ] تریلینگ استاپ دارد؟ با چه منطقی؟
- [ ] شرط خروج زودهنگام (غیر از SL/TP)
- [ ] مدیریت سرمایه: حجم ثابت یا درصد ریسک از موجودی؟
- [ ] فیلترها: ساعت معاملاتی، روند تایم‌فریم بالاتر، اخبار، حداقل نوسان
- [ ] امکان چند پوزیشن همزمان یا فقط یکی؟

### تنظیمات بک‌تست

- [ ] نماد و تایم‌فریم هدف
- [ ] سرمایه‌ی اولیه، کمیسیون، اسلیپیج
