# M_Plus

اندیکاتور و استراتژی تستر ستاپ **FVG + Engulf** برای TradingView (Pine Script v6).

منطق کامل با نقل‌قول مستقیم از فایل صوتی در [`docs/SPEC.md`](docs/SPEC.md) مستند شده است.

---

## ستاپ در یک نگاه

یک FVG دست‌نخورده در تایم **۱۵ دقیقه** پیدا کن. در تایم **۱ دقیقه** صبر کن قیمت داخلش
برگردد. کندلی که وارد ناحیه شده «کندل مرجع» است. اگر حداکثر تا **۱-۲ کلوز** داخل ناحیه
بخورد و بعد **سریع (تا ۳-۴ کندل)** یک کندل بالاتر/پایین‌ترِ سایه‌ی کندل مرجع کلوز کند،
همان‌جا وارد شو با ریسک به ریوارد **۱:۳**.

باطل می‌شود اگر: قیمت کامل از ناحیه رد شود · سه کلوز داخلش بخورد · بیش از ۳-۴ کندل طول بکشد.

## نحوه‌ی استفاده

1. در تریدینگ‌ویو: `Pine Editor` → محتوای فایل `.pine` را paste کن → `Save` → `Add to chart`
2. **چارت را روی تایم‌فریم ۱ دقیقه بگذار.** تایم FVG از ورودی خوانده می‌شود، نه از چارت.
   اگر چارت را روی تایمی بالاتر از تایم FVG بگذاری، اسکریپت روی چارت هشدار می‌دهد.
3. نتایج در تب `Strategy Tester` + جدول خلاصه‌ی بالا-راست چارت

### ورودی‌های کلیدی

| ورودی | پیش‌فرض | توضیح |
|---|---|---|
| `FVG timeframe` | `15` | تایم تشکیل FVG |
| `Max closes inside the gap` | `2` | سه کلوز = باطل |
| `Max bars to engulf` | `4` | مهلت اینگالف از لحظه‌ی ورود به ناحیه |
| `Max reference-candle updates` | `1` | طبق فایل صوتی فقط یک بار |
| `Reward : Risk` | `3.0` | «یک به سه» |
| `Stop loss placement` | `Swing since gap entry` | ← سؤال باز #۱ |
| `Risk per trade %` | `1.0` | حجم بر اساس ریسک محاسبه می‌شود |
| `EMA trend filter` | خاموش | در فایل صوتی فعلاً کنار گذاشته شد |
| `Partial exit + break-even` | خاموش | در فایل صوتی تصمیم قطعی نشد |

## معیار سنجش نتیجه

بک‌تست دستی که در خود فایل صوتی شمرده می‌شود: **۱۸ ورود و ۱۵ تی‌پی در ۵ روز**.
نکته‌ی صریح خودش این است که مزیت این ستاپ **تعداد معامله‌ی بالا** است نه وین‌ریت بالا —
با ۱:۳ حتی وین‌ریت ۳۰-۴۰٪ هم سودده است.

پس اگر بک‌تست تعداد معامله‌ی خیلی کمتری داد، یعنی یکی از فیلترها سخت‌گیرانه‌تر از منظور
اوست — احتمالاً `Max bars to engulf` یا `Max closes inside the gap`.
جدول خلاصه به همین دلیل `Trades / day` را نشان می‌دهد.
