# محل قرار دادن اسکرین‌شات‌ها

تصاویر گرفته‌شده از ویدیو را همین‌جا به صورت `.png` یا `.jpg` بگذارید.

## از چه لحظه‌هایی عکس بگیرید

مهم‌ترین‌ها به ترتیب اولویت:

1. **پنل تنظیمات اندیکاتور** — نام و مقدار پیش‌فرض هر پارامتر
2. **چارت با سیگنال ورود** — جایی که دقیقاً می‌گوید «اینجا وارد می‌شویم»
3. **چارت با حد ضرر و حد سود** — جای دقیق قرارگیری خطوط
4. **هر فرمول، عدد یا نسبتی که نوشته شده**
5. **مثال معامله‌ی ناموفق** — برای فهمیدن شرایط باطل شدن سیگنال
6. **خروجی Strategy Tester** — اگر نتیجه‌ی بک‌تستی نشان داده

## نام‌گذاری

اگر شماره‌گذاری با ترتیب ویدیو باشد خیلی کمک می‌کند:

```
01-settings.png
02-entry-long.png
03-sl-tp.png
04-failed-example.png
```

اگر transcript تایم‌استمپ دارد، اضافه کردن زمان به نام فایل عالی است:
`02-entry-long-t04m12s.png`
